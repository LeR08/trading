Help & Resources
Comment obtenir vos clés API Kraken:
  1. Connectez-vous à votre compte Kraken
  2. Allez dans Settings → API
  3. Cliquez sur Generate New Key
  4. Sélectionnez les permissions nécessaires
  5. Copiez la clé et le secret (le secret n'est montré qu'une fois!)
Sécurité:
  • Ne partagez jamais vos clés API
  • Activez 2FA sur votre compte Kraken
  • Limitez les permissions API au strict minimum
  • Révoquez les clés inutilisées
